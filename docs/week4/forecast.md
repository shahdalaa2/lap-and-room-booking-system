## Updating the forecast
After each sprint:
1. Count the story points for stories that are fully completed according to the team's Definition of Done.
2. Record the actual velocity for that sprint.
3. Use the team's recent average velocity to estimate how many sprints the remaining backlog may need.
4. Update the forecast if the backlog or team capacity changes.

## Important note
This is a provisional forecast, not a committed deadline. The 12-point velocity is an assumption until the team has real sprint results. Only stories that meet the team's Definition of Done should count as completed.
